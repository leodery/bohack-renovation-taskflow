# 厨房换砖 · 四分钟路演

打开[扫码体验](https://leoder.tail57564b.ts.net/?show=1)。要从头彩排，可打开新浏览器会话。

| 时间 | 操作 |
| --- | --- |
| 0:00–0:45 | 切到住户，先展示正在执行的方案。点「填入示例」并发起换砖变更。 |
| 0:45–2:00 | 切到设计师，对照原方案与 AI 专业表述，填写说明并确认可行。 |
| 2:00–3:15 | 切到施工方，核对施工条件并确认可行。展示现场照片上传入口。 |
| 3:15–4:00 | 切回住户，查看意见和照片，确认本版调整。展示新执行版本生效。 |

材料无法到货也可从施工方发起，沿用同一套三方确认流程。

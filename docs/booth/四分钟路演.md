# 厨房换砖 · 四分钟路演

打开 [路演模式](https://leoder.tail57564b.ts.net/?show=1)。同一浏览器保留进度。要从头彩排，打开新浏览器会话。

| 时间 | 讲什么 | 操作 |
| --- | --- | --- |
| 0:00–0:45 | 住户要求换厨房墙砖。新砖晚到，瓦工已约好。若现场先铺，发现问题后可能要拆、重做，三方都承担损失。 | 点击「查看冲突」展示现场拦截，指出新版图纸核验不能跳过。 |
| 0:45–2:10 | AI 从改过的备注中找出到货和瓦工档期冲突，并引用原话。瓦工待工费由施工方核实。 | 现场输入「砖周五才到，瓦工只约了周四，待工费还没报价」，点击「分析这句备注」。 |
| 2:10–3:15 | 说明已确认的材料报价差额，以及当前锁定的任务。 | 台前先点「查看冲突」→「恢复核验并查看新排程」→「提交给三方确认」→「准备前两方演示确认」。台上展开报价和确认记录。 |
| 3:15–4:00 | 最后一个确认由住户完成，项目经理发布后，变更锁解除，施工仍按前置条件执行。 | 点「切换到下一位确认人」→「确认本版方案」→「切回项目经理发布」→「发布新版排程」。 |

预置的设计与施工确认用于合成案例。备注分析在配置本机模型时显示「AI 辅助分析」，模型不可用时显示「规则提示」。分析本身不会修改排程或确认状态。

**20 字内简介**　让装修变更可核对、可确认、可执行

## 评审入口

- [扫码体验同款网页](https://leoder.tail57564b.ts.net/?show=1)，打开后进入项目经理演示视角。
- [四分钟路演操作稿](四分钟路演.md) · [海报二维码 SVG](demo-qr.svg) · [二维码 PNG](demo-qr.png)
- 展台链接随演示主机在线可用。离线于展台时，也可下载仓库并运行本机版。首次安装 Python 依赖需要网络。

## 本机复现

1. 安装 Python 3.11 或更新版本，下载完整仓库。
2. Windows 双击仓库根目录的 `start-demo.cmd`。安装完成后打开 [本机演示](http://127.0.0.1:8775/?show=1)。
3. 从「查看冲突」开始。依次恢复核验、比较排程、完成确认并发布。点击「查看返费结果示例」查看另一个已填好的案例。换新浏览器会话可重新体验。

## 建议评审的三步

1. **工序拦截**。误删图纸核验后，检查受影响工序与责任人。正式排程仍可使用。
2. **影响对比**。恢复必要工序后查看新旧日期、材料报价依据、瓦工待工费。待工费由施工方核实。
3. **确认后执行**。设计、施工、住户确认当前版本，项目经理发布。新版任务按依赖逐步解锁。可在施工页用[厨房墙砖样片](../../demo-assets/kitchen/)体验上传。

返费、报价、角色、照片与确认记录均为合成演示数据。照片初审按时间、角度、内容指出疑点，人工记录结论。模型服务需单独配置，未配置时保留规则检查或标示人工复核。

## 技术与复现

后端使用 Python、Flask、Waitress 和 SQLite。图片使用 Pillow 解析，前端使用原生 HTML、CSS 与 JavaScript。依赖版本见 [requirements.txt](../../requirements.txt)。施工照片检查依据见 [PHOTO_STANDARDS.md](../../PHOTO_STANDARDS.md)。
